API Endpoints

POST/convert

Convert a Markdown document to HTML. Body: {"markdown": "..."}. Returns {"html": "..."}.

curl -X POST https://147.15.103.217.sslip.io/md2html/convert \\
  -H "Content-Type: application/json" \\
  -d '{"markdown": "# Title\\nText."}'

GET/health

Liveness probe. Returns service uptime and status JSON. No auth required.

curl https://147.15.103.217.sslip.io/md2html/health
# {"status":"ok","uptime":4321}

GET/docs

Plain-text API usage guide with request and response examples for the live v1.5.0 service. Read the API docs.

# open in a browser
https://147.15.103.217.sslip.io/md2html/docs

GET/payment

Returns the Litecoin wallet, fixed package size, included calls, confirmation requirement, and claim endpoint.

curl https://147.15.103.217.sslip.io/md2html/payment

POST/payment/claim

Verify a confirmed Litecoin txid and credit prepaid calls to the API key in X-API-Key.

curl -X POST https://147.15.103.217.sslip.io/md2html/payment/claim \\
  -H "Content-Type: application/json" \\
  -H "X-API-Key: ***" \\
  -d '{"txid":"<64-hex-txid>"}'

GET/usage

Current month's call count and remaining free quota. Returns balance JSON.

curl https://147.15.103.217.sslip.io/md2html/usage
# {"calls_made":7,"free_tier_limit":10,"remaining":3}

GET/stats

Aggregate service metrics: total calls, unique clients, per-endpoint and status counts, potential conversions, and average latency. Public, read-only.

curl https://147.15.103.217.sslip.io/md2html/stats
# {"total_calls":12340,"unique_ips":42,"calls_by_endpoint":{}}

GET/swagger.json

Machine-readable OpenAPI 3.0 specification for integrating the live API. View the OpenAPI spec.

FAQ

  • Is it free?
    Yes — the first 10 billable calls are free. After that, 0.001 LTC buys 100 prepaid calls. No subscription or credit card.
  • Do I need an account?
    Free calls can use source-IP billing without signup. For a separate quota or prepaid calls, mint an API key with GET /register and send it in X-API-Key.
  • What about rate limits?
    Clients are capped at 30 requests/minute. Exceeding it returns HTTP 429. Exhausting the free allowance returns 402; a confirmed payment claim adds prepaid calls.
  • Can I self-host?
    Yes — MD2HTML is open source at github.com/danielbenevides-ops/md2html-api. Clone the repo, run the server, and point your requests at your own instance. Full source, no black box.
