## 1. Reddit — r/webdev
**URL:** https://www.reddit.com/r/webdev/

**Why relevant:** 1.2M+ members; active daily discussion of tools, APIs, libraries. Weekly "Showoff Saturday" thread is explicitly for self-promo of projects. Developers routinely ask "what API should I use for X?" — high intent-to-adopt.

**Self-promo draft:**

## 2. Dev.to
**URL:** https://dev.to/

**Why relevant:** 900K+ developers writing and reading tutorials. Tutorials that *use* an API (e.g., "Build a blog with MD2HTML") drive organic discovery. Tag-based reach (#webdev, #api, #markdown) with strong SEO. Non-spammy self-promo via educational content is the norm.

**Self-promo draft:**
> I open-sourced a free markdown-to-HTML API — no signup, no rate limits on the free tier. Here's how to integrate it in 3 lines and why I built it. Would love your feedback and feature requests.

## 3. Hacker News (Show HN)
**URL:** https://news.ycombinator.com/

**Why relevant:** "Show HN" posts are the canonical launch channel for developer tools. Front-page exposure can drive 10K–50K visits in hours. Audience skews technical and critical — honest, no-hype posts perform best; any utility API with a real demo fits.

**Self-promo draft:**
> Show HN: MD2HTML API — a free, no-auth markdown-to-HTML endpoint. Live demo + source. Built it because existing converters were either paid, rate-limited, or required an SDK.

## 4. Product Hunt
**URL:** https://www.producthunt.com/

**Why relevant:** The #1 launch platform for dev tools and SaaS. A "Product of the Day" finish delivers 5K–20K early users. Developer-tools category is competitive but high-signal; visitors come specifically to find and try new APIs.

**Self-promo draft:**
> MD2HTML API — the fastest free way to convert markdown to HTML. No account, no SDK, one endpoint. We're live today — makers, what would make this useful in your stack?

## 5. Discord — Developer communities (e.g., "The Coding Den", "Devs in Tech")
**URL:** https://discord.com/ (search: "developer discord servers")

**Why relevant:** Real-time #self-promotion and #showcase channels let you plug APIs to active devs seeking tooling. Smaller but higher engagement than forums; instant feedback loops. Free, no algorithm to game. Multiple servers (Devs in Tech ~30K, The Coding Den ~50K) compound reach.

**Self-promo draft:**
